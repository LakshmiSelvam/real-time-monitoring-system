# Real Time Monitoring Systen

### Pre-requisite

    Node JS
    Npm

#### Cloning and Running the Application in local

Clone the project into local

In order to run the npm packages type the following command.

    npm install

In order to run the application Type the following command

    npm start

The Application Runs on localhost:3000

### Testing Scripts

#### To run all test cases

    npm test

After changing the test files, if you want to run all the test cases, you can use

    npm test run

#### To run indivdual file

    npm run test -- file_name

## Production mode

    Open command prompt and navigate to the project folder

    For Building :
    	 run command `npm run build`
    Example :
    	<Root Directory>\ > `npm run build`
    		On successful execution, the production build will be generated and placed inside the project folder.
